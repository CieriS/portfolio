#Cieri Samuele Portfolio

##The project
The project was developed using HTML, CSS and JavaScript. Subproject may be realized through other technologies.
Site has been designed to be responsive on all devices.
Code has been written using a modular and scalable approach, with separate files for each component (header, footer, navigation bar, main content).

##Technologies
- HTML5
- CSS3
- JavaScript ES6
- php
- SQL
- Bootstrap 5.3.0
- Tailwind CSS 3.3.5
